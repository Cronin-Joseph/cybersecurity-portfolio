# AWS Cloud Infrastructure

## Overview
An individual proof-of-concept cloud infrastructure project completed as part of my BSc Digital Forensics and Cyber Security studies at TU Dublin.

The project involved designing and configuring a cloud environment using Amazon Web Services (AWS), with a focus on network architecture, resource deployment, availability and storage.

## Architecture and Components
- **VPC:** Created a Virtual Private Cloud to provide an isolated network environment.
- **Subnets:** Configured public and private subnets across two Availability Zones.
- **EC2:** Deployed virtual machine instances within the cloud environment.
- **Bastion Host:** Included a bastion host to support controlled administrative access.
- **RDS:** Incorporated a managed relational database service.
- **Load Balancer:** Configured load balancing to distribute incoming traffic.
- **Auto Scaling:** Included scaling capabilities to respond to changes in demand.
- **S3:** Used Amazon S3 for static website hosting and backup storage.

## Technologies
- Amazon Web Services (AWS)
- VPC and subnet networking
- EC2
- RDS
- S3
- Load balancing and Auto Scaling

## Learning Outcomes
- Gained practical experience designing cloud infrastructure.
- Developed an understanding of public and private cloud networking.
- Explored availability and scalability through AWS services.
- Improved understanding of cloud storage, compute and database services.
