# Threat Hunter Toolkit

## Overview
An individual PowerShell project developed as part of my BSc Digital Forensics and Cyber Security studies at TU Dublin.

The toolkit contains scripts designed to identify potentially suspicious activity through log and event analysis.

## Features
- **Suspicious HTTP activity:** Identifies unusual HTTP response codes and suspicious IP addresses.
- **SSH authentication monitoring:** Highlights failed SSH authentication attempts that may indicate brute-force activity.
- **PowerShell analysis:** Searches for indicators such as encoded commands, execution policy bypasses and suspicious downloads.
- **Combined execution:** Includes a script to run the individual checks together.

## Technologies
- PowerShell
- Windows security and event logs
- Network and security analysis concepts

## Learning Outcomes
- Developed practical PowerShell scripting skills.
- Explored indicators of suspicious activity.
- Practised identifying potential brute-force and command execution behaviour.
- Improved understanding of basic threat hunting techniques.
