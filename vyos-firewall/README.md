# VyOS Firewall Implementation

## Overview
A group-based firewall configuration project completed as part of my BSc Digital Forensics and Cyber Security studies at TU Dublin.

The project involved implementing and testing firewall rules using VyOS, a network operating system with firewall and routing capabilities.

## My Contribution
My individual contribution focused on the VyOS firewall configuration and testing.

- Configured firewall zones for LAN, WAN and LOCAL traffic.
- Implemented zone-based firewall policies.
- Applied a default-drop approach to traffic that was not explicitly permitted.
- Created firewall rules to control traffic between zones.
- Tested connectivity and firewall behaviour using ICMP and ping.
- Investigated firewall responses to port scanning and SYN scan activity.
- Examined logs and behaviour during brute-force testing.

## Technologies and Tools
- VyOS
- Command-line interface (CLI)
- Zone-based firewall configuration
- ICMP and ping testing
- Port and SYN scanning
- Firewall logging

## Learning Outcomes
- Gained practical experience configuring a network firewall.
- Developed an understanding of zone-based security policies.
- Explored default-deny firewall principles.
- Practised testing firewall rules and analysing network traffic.
- Improved understanding of network security and access control.
